# سجل استكمال زبيد

## مكتمل ومحفوظ

- نسخة المصدر قبل هذه المهمة: `.codex-backups/zubayd-platform-20261023`.
- هوية المالك في `brand.config.json`، مع إبقاء بيانات العملاء والأجهزة مستقلة. الشعار الرسمي لم يقدم؛ الأيقونات مؤقتة.
- فصل مخازن الشركات على الخادم عبر AsyncLocalStorage ومسارات مستقلة، وتحديد صلاحيات الشركة ومالك النظام.
- صفحة إضافة الشركات والفروع، واختيار الشركة النشطة.
- اختبار `scripts/zubayd-companies.test.mjs` نجح: منع الوصول لشركة أخرى، فصل الاعتمادات والورديات، تزامن الطلبات، بقاء ملف البيانات القديم دون تعديل.
- اختبارات تكامل Hikvision السابقة 19/19 نجحت بعد طبقة الشركات.
- مشروع Android حقيقي في `android`، وأُنتج `releases/android/Zubayd-debug.apk` بتوقيع تجريبي والتحقق عبر apksigner. يحتاج خادم HTTPS؛ لا عنوان IP ثابت داخل APK.
- مشروع Windows في `desktop` مع إعداد أول تشغيل وخادم Node مضمّن وتصميم نسخ احتياطي مشفر. لم يُنتج Setup.exe حتى الآن.
- بناء خادم Node المستقل نجح: `dist-server/server/index.mjs`، عبر `scripts/zubayd-build-server.mjs`.
- اكتملت تدفقات الموظف والوجه والكروت والصلاحيات داخل نافذة الموظف، وإعادة الاتصال دون فقد المدخلات، والسحب والتشخيص داخل الحضور.
- اكتملت الاستعادة المرحلية مع الاحتفاظ بمجلد البيانات السابق، وواجهة إعداد HTTPS الأصلية في مشروع Windows؛ اختبارات المنطق والنسخ نجحت على بيانات مؤقتة.
- دليل التشغيل 21 موضوعاً مرتبطاً بالوظائف الحالية، بما فيها الشركات والتثبيت والنسخ وHTTP 400.
- قبول المتصفح ناجح على 13 شاشة وستة مقاسات، واختبارات الوجه ناجحة على المحاكي. اختبارات المصدر 70/70 وISAPI 19/19 ناجحة.
- تشغيل حزمة خادم مستقلة بعميل ومدير جديدين نجح دون خدمة بيانات أو مصادقة خارجية لمركز Access Control. حجب المسارات الخاصة 403 ناجح.
- التقرير النهائي والتقرير الأمني وتعليمات التثبيت في ملفات `docs/ZUBAYD_*_AR.md`، وكشف الملفات في `docs/ZUBAYD_CHANGES.json`.

## قيد التنفيذ

- تغليف Windows واختبار المثبت متعذران: تنزيل Electron وelectron-builder واجه ERR_SSL_CIPHER_OPERATION_FAILED. لم يُعطل HTTPS أو فحص الشهادات، ولا يوجد Setup.exe.
- تجربة APK على هاتف فعلي وخادم HTTPS، وتوقيع إصدار Android/AAB. لا يوجد جهاز adb متصل.
- قراءة مصادق عليها جديدة من Hikvision للفترتين؛ الاعتماد غير متاح لجلسة Codex. لا تُعد نتائج المحاكي نجاحاً جديداً على العتاد.
- الشعار الرسمي وتوقيع النشر، واعتماد ترحيل/صلاحيات الإنتاج وإعادة تشغيل إعداد الحماية الإضافي لـVite عند الحاجة.

## حدود السلامة

لم تنفذ أوامر تعديل أو فتح أبواب على جهاز Hikvision الحقيقي، ولم تُنقل أو تُحذف بيانات الإنتاج. لم يُوقف SSH أو Tailscale. الاختبارات تجري على مخازن ومحاكيات منفصلة. لا يُدّعى نجاح تسجيل أو سحب مصادق عليه من الجهاز الحقيقي دون دليل.
